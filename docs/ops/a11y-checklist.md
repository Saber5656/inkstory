## Global gates

- `eslint`/`jsx-a11y` is configured and must remain green; the repository test covers the security lint guard.
- Playwright axe must report zero serious/critical findings on every discovered route in both Japanese and English. The earlier `.page-dots` role violation is fixed; subsequent Chromium/WebKit ja/en sweeps pass. WebKit coverage is valid only for routes actually discovered by the fixture state.
- Audio captions for user narration are not automatic speech-to-text in the MVP. If narration captions become a requirement, add an explicit local transcription design and privacy review; do not imply that recorded audio is captioned.
- Inline script is intentionally suppressed by CSP. Any future inline code must be replaced by bundled module code; no exception is recorded here.
- Keyboard-only creation, screen-reader review, touch-target audit, and toddler-mash/device checks require dated manual evidence. Unit tests and HTTP 200 responses cannot close those gates.
