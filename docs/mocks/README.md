# 画面モック（v1）

`screens.html` はブラウザで開くだけで動く自己完結の画面モックです（外部依存なし・ビルド不要）。
左のリストから画面を選ぶと、中央にモック、右に「どの要件からその UI が来ているか」の注釈が出ます。

**作成方針:** フロントエンドの画面コードは一切参照せず、以下の要件ドキュメントのみから抽出しました。

- `docs/DESIGN.md` §2（スコープ）、§3（ペルソナ/ジャーニー）、§5（ウィザード）、§6.6（ステージ）、§8（UI/UX）、§9（PWA）、§10.5（アビュースケース）
- `docs/issues/` 03, 06, 07, 09, 12, 16, 18, 19, 20, 21, 22, 23, 25, 26, 28
- `docs/decisions/ADR-005`（ローカルのみのデータ方針）

モックは **要件の可視化** が目的です。色・余白・フォントは issue 03 のトークン方針（紙のクリーム地 + クレヨン系アクセント、本文 16px 以上、タッチ領域 48px 以上）に沿った仮置きで、最終ビジュアルではありません。
