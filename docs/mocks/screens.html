ウィザード 1 — とりこみ（capture）

状態機械 capture → crop → mask → rigType → joints → preview → saved の最初のステップ。

  1. 1
    「写真をとる」= ファイル入力（capture=environment）を大ボタンとして表示。対応環境ではライブプレビュー付きカメラモーダルに昇格し、失敗時はエラー無しでファイル入力へ静かにフォールバック。issue 06-2,3
  2. 2
    「しゃしんをえらぶ」= ギャラリー/ファイルからの選択。issue 06-2
  3. 3

ウィザード 2 — きりとり（crop）

写真に写り込んだ机や背景を減らす。マスクの精度に直結するので一級の手動ステップ。

  1. 1
    画像は作業領域いっぱい。8 ハンドルの矩形（初期 90% 中央）、内部に三分割グリッド、下の画像はピンチ/ホイールでズーム・パン。ハンドルのヒット領域は 48px。issue 07-1,3,5
  2. 2
    90° 左右回転ボタン + ±15°（0.5° 刻み）の微調整スライダー。回転はクロップより先に適用し、矩形は画面に対して常に水平。issue 07-2
  3. 3
    「もどる」= 取り込みへ（画像は破棄）。「つぎへ」= 切り抜き済み画像を持ってマスクへ。issue 07-7
  4. 4
    最小 128×128px。出力の長辺は再度 2048px 以下に丸める。キーボードでは矢印 1px / Shift+矢印 10px で移動。issue 07-3,4,5
  5. 5
    多言語化されたヘルプ文「キャラクターのまわりをはこでかこんでね」。issue 07-6

ウィザード 3 — マスク

自動セグメンテーションの結果をブラシで直す。失敗時のトースト表示を重ねている。

  1. 1
    入場時に Worker で自動切り抜き（進捗スピナー、2048² で 2 秒以内）。絵は不透明、マスクは 50% ティント + 動く破線（reduced-motion では静止）。DESIGN §5.2, §5.3 / issue 09-1,2
  2. 2
    取り消し/やり直し 20 段以上。「きりぬきをみる」で市松模様上の切り抜きプレビューに切替。issue 09-2,3

    ブラシは 追加/消去、サイズ S/M/L（ズームに相対）。指・ペン・マウス対応、2 本指でパン/ズーム。issue 09-3
  4. 4
    「もう一回自動」+ 感度スライダー。再実行も取り消し可能。issue 09-4
  5. 5
    最大成分が 2% 未満 / 98% 超のときは「みつからなかった」ヒントを出し、空のマスク + ブラシ選択状態で開く。絵は決して拒否しない（G2）。DESIGN §2.2, §5.2 / issue 09-1

ウィザード 4 — うごきかた（rigType）

人型（スケルトン）か切り抜き（エフェクトのみ）かを 2 枚のカードで選ぶ。

  1. 1
    「うごくからだがある（ひとがた）」= humanoid。以降「かんせつ」ステップへ。DESIGN §5.1 / issue 09-6
  2. 2
    「そのままうごかす」= cutout。かんせつをスキップしてプレビューへ。どんな絵も拒否しない（G2）。DESIGN §2.2, §6.4
  3. 3
    姿勢モデルが自信ありのキーポイントを返したときだけ「ひとがた」を既定選択。モデル無し・低信頼なら既定なし（明示的に選ばせる）。モデルが無くても完全に動く。issue 09-6 / ADR-004
  4. 4
    非技術者の親向けの説明文。用語は子ども向けの平仮名。DESIGN §3 / §8.7

ウィザード 5 — かんせつ（joints）

16 個の関節ピンを絵の上に置く。姿勢モデルが無くても必ず通れる「保証された経路」。

  1. 1
    切り抜きの上に 16 ピン + 15 本の骨線。ピンのヒット領域 44px、ラベルは子ども向け（「みぎて」など）。ズーム/パンはマスク編集と共通。DESIGN §5.5 / issue 12-4
  2. 2
    ピンかリスト項目のタップで選択。選択中はドラッグ・矢印キーで移動し、ドラッグ中は拡大鏡（ルーペ）を出す。issue 12-4
  3. 3
    検証警告は非ブロッキング：マスク外のピン、胴体線をまたぐ左右の手足。脈打つ枠 + 一覧で示すが「つぎへ」は止めない。DESIGN §5.5 / issue 12-5
  4. 4
    モデルの平均信頼度 ≥0.3 なら自動配置 + 「じどう」バッジ。それ以外はテンプレ姿勢で仮置きし「てんをからだにのせてね」トースト。「テンプレに戻す」は常に利用可。右 = キャラの右（画面左）を小さなアバターで示す。DESIGN §5.4 / issue 12-2,3 / ADR-004

えほんプレイヤー（キッズモード）
