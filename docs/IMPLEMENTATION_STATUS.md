## Observed integration evidence (2026-09-08)

- Chromium and WebKit: manual drawing → crop/mask/template joints → save → stage → two-page book → player; sample auto-play; route guard; ja/en route axe; strict CSP negative probes; same-origin exchange audit.
- Both engines: six capture tests verify rotated EXIF input, metadata removal, bad-input rejection, crop/texture pixel behavior, and real segmentation worker round-trip.
- Both engines: export → fresh profile import → duplicate import produces independent UUIDs; malicious corpus rejects inputs without database writes. Atomic narration replacement and microphone cleanup have separate regression tests.
- Real rendering is verified independently of DOM navigation. A Canvas existing does not prove the character is visible. Frame rate, deformation, and the browser screenshot matrix have separate evidence.
- Pose remains `unavailable`, as allowed by the spike's acceptance alternative; model card records the actual conversion blocker. No real ONNX inference or physical camera/microphone/wake-lock verification is claimed.
- CI, PR, hosted deployment, and physical-device state are reported in the delivery record. Release and merge are not implied by locally passing checks.
